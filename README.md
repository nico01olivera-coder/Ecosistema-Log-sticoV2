# Ecosistema-Log-sticoV2

## Descripción
Desarrollo de un sistema de gestión para unidades de transporte automatizadas (drones y camiones autónomos), modelado e implementado bajo el paradigma de Programación Orientada a Objetos (POO) y procesamiento de datos con CRUD, expresiones lambda y Streams.

Este proyecto corresponde a la Práctica de Integración 2 de la asignatura Programación II de la carrera de Ingeniería Informática (Universidad Nacional de Itapúa).

## Conceptos Aplicados

* **Abstracción:** Definición de entidades vehiculares genéricas y específicas.
* **Jerarquía y Contratos:** Uso de clases abstractas (`Vehiculo`) e interfaces (`IConectable`).
* **Relaciones de Objetos:** Implementación de Herencia, Realización y Agregación.
* **Polimorfismo:** Ejecución dinámica de patrones de movimiento y sincronización según la instancia del objeto en tiempo de ejecución.
* **CRUD:** Gestión completa de datos de la flota (crear, listar, buscar, modificar y eliminar).
* **Lambda y Streams:** Procesamiento funcional y manipulación eficiente de colecciones.

## Tecnologías

* **Lenguaje:** Java
* **IDE:** NetBeans
* **Diseño de Software:** UML (draw.io)
